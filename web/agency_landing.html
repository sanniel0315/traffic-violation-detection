§ 02

傳輸協定 · Choose your transport

依機關平台 / 客戶端能力選擇最合適的協定
首選 / PRIMARY

RTSP

即時串流協定
業界主流，多數 VMS / NVR 與監控錄影設備原生支援。Jetson 經 go2rtc 直接 passthrough，無重編碼延遲低。
RECOMMENDED FOR
機關既設 NVR / VMS
低延遲監看牆
長時間錄影歸檔
WEB

HLS

HTTP Live Streaming
Apple 標準，現代瀏覽器、行動裝置原生播放。基於 HTTP 易穿透防火牆，延遲較高（5-10 秒）。
RECOMMENDED FOR
Web Dashboard 嵌入
跨平台行動裝置
外網 / VPN 後存取
LEGACY

MJPEG

Motion JPEG over HTTP
老學派但通用，純 JPEG 連續傳送。每幀獨立解碼支援度極廣。代價是頻寬高（10+ Mbps/cam），需 go2rtc 端開啟轉碼。
RECOMMENDED FOR
低資源 / 老舊 NVR
截圖 / 影像分析 pipeline
不支援 H.264 解碼設備
REALTIME

WebRTC

即時點對點傳輸
最低延遲（~200ms），瀏覽器 P2P 拉流。需 STUN / TURN 協商。go2rtc /api/ws 信令交換。
RECOMMENDED FOR
即時遙控 / 互動場景
低延遲 web 監看
多人協作觀看
§ 03

對外 REST API · Programmatic access

查 stream 列表、抓 VD 車流 / 壅塞報表（需 X-API-Key Header）
# 取得當前所有可用 stream + bytes 統計 curl -H "X-API-Key: tvd_xxxxxxxxxxxxxxxx" \ http://192.168.0.108:8000/api/v1/external/streams | jq . # 取 VD 車流報表（CSV） curl -H "X-API-Key: tvd_xxxxxxxxxxxxxxxx" \ "http://192.168.0.108:8000/api/v1/external/vd-report?\ start_time=2026-05-26T00:00:00&end_time=2026-05-26T23:59:59&\ bucket=5m&format=csv" # 取壅塞報表（JSON） curl -H "X-API-Key: tvd_xxxxxxxxxxxxxxxx" \ "http://192.168.0.108:8000/api/v1/external/\ congestion-report?bucket=1h" | jq .

§ 05

網路規格 · Firewall rules

機關防火牆需開放（從機關平台到 Jetson 方向）
Proto Port Service Purpose
TCP8000traffic-apiREST API · 對外報表 · 健康檢查 · Swagger
TCP8554go2rtc RTSPRTSP 拉流 · 機關平台主要對接通道
TCP1984go2rtc HTTPHLS / MJPEG / WebRTC 信令
UDPdynamicWebRTC mediaWebRTC 媒體流 · 由 STUN / TURN 協商

WebRTC 媒體流走 UDP，若機關防火牆有嚴格限制，建議改用 RTSP（TCP 8554）作為主要對接方式。 所有 TCP port 預設綁定全介面，若需限制存取來源 IP，請告知系統管理員設定 iptables 規則。
