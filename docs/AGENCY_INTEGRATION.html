3.1 端點

GET  http://10.42.38.35:8000/api/v1/external/streams
Header:  X-API-Key: <你的 API Key>

對外 API 完整端點清單（皆為 GET，base http://10.42.38.35:8000）：

路徑 說明 scope
/api/v1/external/streams 即時影像串流清單（cam id + RTSP/HLS/MJPEG/WS URL） streams
/api/v1/external/realtime 即時 VD 車流報表（mode=minute 分鐘累積 / mode=window 滾動視窗） vd_report
/api/v1/external/vd-report VD 車流報表 — 指定時間區間（start_time/end_time ISO8601） vd_report
/api/v1/external/vd-report/latest VD 車流報表快捷 — 最近 N 分鐘 + 統計摘要 vd_report
/api/v1/external/congestion-report 壅塞報表 — 指定時間區間 congestion_report
/api/v1/external/congestion-report/realtime 壅塞即時報表 congestion_report
/api/v1/external/congestion-report/latest 壅塞統計快捷 — 最近 N 分鐘 + 摘要 congestion_report

8. 故障排查

症狀 可能原因 處置
RTSP 連不上 防火牆 / 路由 確認 nc -zv 10.42.38.35 8554 通
影像卡頓 平台端 buffer / 頻寬 改 TCP transport；確認頻寬 >10 Mbps/cam
無影像但連得上 上游攝影機掛 打 /api/v1/external/streams 看 online 欄位
API 401 API Key 錯 / scope 不足 確認 Header X-API-Key 跟所需 scope
API 429 速率限制 降低呼叫頻率（預設 60 req/min，靜態金鑰 120）
